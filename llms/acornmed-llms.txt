# AcornMed (金橡医学)

> AcornMed Biotechnology Co., Ltd. is a Beijing-headquartered precision-oncology company founded in
> 2018, with subsidiaries in Tianjin and Qingdao. It develops next-generation-sequencing (NGS)
> diagnostics for solid tumors and hematologic malignancies and runs CAP/ISO 15189 central-laboratory
> testing and companion-diagnostic programs for pharmaceutical partners. AcornMed publishes no public
> API, developer portal, SDK, or machine-readable contract; this file is generated by API Evangelist
> from the public website and is not published by AcornMed.

## Tests and products

- [Tests overview](https://en.acornmed.com/tests/index.html)
- AcornUI-SEEK — non-invasive urine genomic test to help rule out bladder, ureteral and renal-pelvic cancer (NMPA approved 2024).
- AcornUI-MRD — urine-based monitoring for bladder cancer recurrence.
- AcornUPro-SEEK — urine test supporting prostate cancer screening.
- AcornOne 808 — solid-tumor NGS panel.
- AcornHema 521 — hematologic malignancy NGS panel.
